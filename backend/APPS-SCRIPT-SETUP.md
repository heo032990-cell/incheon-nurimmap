# Apps Script v90 적용

기존 Google Drive 연결에 사용 중인 Apps Script 프로젝트 하나를 업데이트합니다.

1. 이 폴더의 `google-apps-script-v90.gs` 전체 내용을 복사합니다.
2. 기존 Apps Script 코드를 교체하고 저장합니다.
3. 배포 → 배포 관리 → 기존 웹 앱의 편집(연필) → 버전: 새 버전 → 배포를 누릅니다.
4. 기존 웹 앱 주소와 WEBHOOK_SECRET은 그대로 유지합니다. 새 프로젝트나 새 URL을 만들 필요가 없습니다.

v87에서 사용하던 Drive·Sheets·HTML→PDF 서비스만 사용하며 새 권한 서비스를 추가하지 않았습니다.

## 달라지는 저장 방식
- 설문 있음: 기본정보와 설문 답변으로 PDF·응답 시트·CSV를 생성합니다. 기본 개인정보 동의서와 전자서명은 넣지 않습니다. 설문 안에 직접 추가한 동의 문항은 설문 답변이므로 유지합니다.
- 설문 없음: 프로그램 폴더에 참여 명단 CSV만 만듭니다. 빈 개인 신청서 폴더나 자동 PDF를 만들지 않습니다.
- 첨부형: 명단 CSV와 신청서 모음 폴더의 업로드 파일을 관리합니다. 업로드 파일 자체의 내용은 수정하지 않습니다.
- 취소·수정 후 프로그램 CSV 갱신도 함께 적용됩니다.

웹앱에는 기본정보와 기본 동의 응답·서명·당시 동의 문구가 남습니다. 기존 과거 PDF는 일괄 삭제·재생성하지 않습니다.

웹·Supabase는 v90 변경 사항을 반영할 수 있게 준비되어 있습니다. 이 Apps Script 배포가 끝나야 CSV 열 제외와 파일 정리가 모두 적용됩니다.
