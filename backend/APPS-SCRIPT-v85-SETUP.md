# 같은 Apps Script로 설문 PDF 저장하기 (v85)

이 수정은 사이트 배포가 아닌 Google Apps Script 교체본입니다. 현재 웹 v84와 설문 서버 v7을 그대로 사용합니다.

기존 연결은 파일을 Drive에 저장하지만 v78 설문 출력은 DocumentApp으로 문서를 먼저 생성했습니다. v85는 이 의존성을 제거하고 HtmlService로 설문 내용을 PDF로 변환해 기존 폴더에 저장합니다. Google 문서 파일을 별도로 생성하지 않습니다. 기존 파일·CSV·시트·기관별 폴더·비밀값 검증·중복 제출 처리 코드는 유지합니다. 기존 문서와 PDF를 삭제하지 않습니다.

적용 방법:
1. 기존 Drive 연결 Apps Script 프로젝트를 엽니다. 새 프로젝트를 만들지 않습니다.
2. google-apps-script-v85.gs 전체 내용으로 기존 코드를 교체하고 저장합니다. WEBHOOK_SECRET 및 폴더 설정은 유지합니다.
3. 배포 → 배포 관리 → 기존 웹 앱 편집 → 새 버전 → 배포. 기존 /exec 주소를 유지합니다.
4. 누림지도 설문 관리에서 신청에 사용을 다시 누릅니다.

현재 도구에는 해당 Apps Script의 코드 수정·배포 기능이 없어 위 Google 적용은 사용자가 수행해야 합니다. 추가 권한이나 서비스 제한이 표시되면 해당 오류를 확인해야 합니다. PDF 변환은 Google 변환 할당량의 영향을 받습니다.

검증: 문법 검사 및 Google 서비스 모의 검사로 DocumentApp 미사용, HTML 이스케이프, 기본정보·답변 포함, PDF 저장 경로 및 재시도 시 기존 파일 재사용을 확인했습니다. 실제 Google 변환·한글 출력 레이아웃·Drive 저장 확인은 적용 후 필요합니다. 이전 버전 복구: google-apps-script-v78.gs.
