# AI 활용 내용

인천 누림지도는 **복지 현장의 요구를 실제 웹서비스로 구현하는 과정에 AI를 활용한 프로젝트**입니다. 담당자가 필요한 기능과 운영 기준을 제시하고, AI가 기획 정리·코드 작성·오류 수정·디자인 시안 제작을 지원했습니다. 결과물은 담당자와 팀원의 피드백, 실제 화면 및 동작 확인을 거쳐 보완했습니다.

## 1. AI 활용 개요

| 구분 | 내용 |
| --- | --- |
| **사용한 AI 도구·모델** | **ChatGPT·Codex**를 활용해 요구사항과 안내 문구를 정리하고, 웹서비스의 코드 작성·수정·검증을 진행했습니다. **ImageGen**은 서비스 아이콘과 비교·투표용 디자인 시안 제작에 활용했습니다. 기록으로 확정되지 않은 세부 모델명은 기재하지 않았습니다. |
| **AI가 담당하는 기능** | 프로그램 검색·등록·신청, 설문 편집, 신청자료 저장 등의 기능 구현을 지원했습니다. 오류 화면을 바탕으로 원인을 분석하고 수정안을 작성했으며, 화면 배열·접근성 관련 기능과 이용 안내를 보완했습니다. 또한 인천의 특징을 반영한 아이콘 시안을 제작했습니다. |
| **AI를 활용한 이유** | 현장에서 필요한 기능을 자연어로 설명하고, 화면과 코드로 구체화하면서 검토하기 위해 활용했습니다. 기능 개발뿐 아니라 화면 구성·문서 작성·디자인을 함께 진행하고, 팀원의 의견을 다음 수정에 반영하는 데 도움이 됐습니다. |
| **AI가 없었다면 어려웠던 부분** | 웹화면, 신청 설문, Google Drive 저장, 관리자 권한 등 여러 요소를 연결하는 코드 작성과 오류 원인 추적에 더 많은 시간과 전문적인 지원이 필요했을 것입니다. 여러 화면 크기에 맞춘 조정과 디자인 시안 비교, 반복적인 수정·검증도 부담이 컸을 것으로 예상합니다. |

### 개발을 지원한 AI와 실제 서비스 기능의 구분

- **AI 개발 지원:** 기능 설계, 코드 작성·수정, 점검 보조, 문서 작성, 아이콘 제작.
- **홍보지 자동입력 보조:** Google Drive의 문자 인식(OCR)으로 홍보지의 글자를 읽고, 프로그램명·기간 등 항목을 코드로 추출하는 방식입니다. 담당자가 내용을 확인한 뒤 활용하는 보조 기능입니다.
- **일반적인 서비스 처리:** 프로그램 검색, 신청 접수, PDF·CSV 생성 등은 구현된 코드와 연결 서비스가 처리합니다. 이러한 기능 전체를 생성형 AI가 실시간으로 판단하거나 수행하는 것은 아닙니다.

## 2. AI 성능 개선 시도

별도의 모델 학습보다는 **요청 내용을 구체화하고 결과를 반복 확인하는 방식**으로 결과물의 적합성을 높였습니다. 주요 시도는 다음 세 가지입니다.

### ① 실제 자료와 구체적인 운영 조건을 함께 전달

**왜 시도했나요?**  
“설문 기능을 만들어 달라”는 요청만으로는 기관의 신청 절차와 자료 관리 방식을 충분히 반영하기 어려웠습니다.

**어떻게 개선했나요?**  
기존 설문 양식, 홍보지, 화면 예시, 팀원의 의견을 제공하고 필요한 동작을 구체적으로 설명했습니다. 예를 들어 같은 설문을 여러 프로그램에 재사용하더라도 작성된 신청서는 실제 신청한 프로그램의 Google Drive 폴더에 저장하도록 기준을 명확히 했습니다.

**어떤 점이 달라졌나요?**  
화면에 보이는 설문뿐 아니라 프로그램 연결, 신청 기록, 자료 저장 방식까지 현장의 운영 흐름에 맞춰 수정할 수 있었습니다.

### ② 실제 오류 화면과 이용자 피드백을 바탕으로 반복 수정

**왜 시도했나요?**  
처음 만든 화면이 실제 사용 환경에서 항상 편리하게 작동하는 것은 아니었기 때문입니다.

**어떻게 개선했나요?**  
제출 오류, 좁은 화면의 배열 문제, 중복 입력 등 실제 사용 중 발견한 문제를 화면과 함께 전달했습니다. 시각장애인 피드백에 따른 날짜 선택 방식도 검토하고, 수정 후에는 브라우저 동작과 신청자료 저장 결과를 확인했습니다.

**어떤 점이 달라졌나요?**  
실제 사용 과정에서 드러난 문제를 기준으로 입력 방식과 화면 배열을 보완하고, 신청 처리와 자료 저장 흐름을 확인하며 완성도를 높였습니다.

### ③ 디자인의 공통 기준을 정한 뒤 프롬프트를 단계적으로 보완

**왜 시도했나요?**  
아이콘이 작은 화면에서도 알아보기 쉽고, 여러 후보를 같은 기준으로 비교할 수 있어야 했습니다.

**어떻게 개선했나요?**  
지도 핀을 공통 형태로 정하고, 인천을 표현하는 바다·다리·등대 등의 상징과 색상을 구체적으로 지정했습니다. 이후 배경, 여백, 선 굵기, 작은 크기에서의 식별성을 고려해 수정 요청을 추가하고, 공통 참조 이미지를 활용해 비교용 후보를 제작했습니다.

**어떤 점이 달라졌나요?**  
공통된 형태를 유지하면서 상징과 색상이 다른 시안을 비교할 수 있었습니다. 현재 적용된 아이콘과 투표용 후보는 구분하여 관리하고 있습니다.

> 위 내용은 작업 방식과 결과물 개선에 관한 설명입니다. 별도 모델 학습이나 temperature 조정, 정확도·작업시간의 정량적 개선 측정은 확인된 기록이 없어 성과로 기재하지 않았습니다.

## 3. 발표용 요약

> 인천 누림지도에서는 AI를 현장의 요구를 실제 서비스로 구현하는 개발 지원 도구로 활용했습니다. 담당자가 신청 절차와 자료 관리 기준을 제시하면 AI가 코드와 화면을 작성하고, 실제 사용 결과와 팀원의 의견을 바탕으로 반복 수정했습니다. 또한 아이콘 제작에도 AI를 활용했습니다. AI의 결과를 그대로 채택하기보다 사람이 운영 기준을 정하고 결과를 확인하는 방식으로 서비스를 발전시켰습니다.
