# v91 프로그램별 설문 신청서 저장 — 직접 적용 안내

이번 수정은 Apps Script만 교체합니다. Netlify·Supabase 변경이나 배포는 필요하지 않습니다.

## 적용
1. 기존 Apps Script 프로젝트에서 기존 전체 코드를 google-apps-script-v91.gs 전체 내용으로 교체합니다.
2. 저장 후 배포 → 배포 관리 → 기존 웹 앱 편집 → 새 버전 → 배포합니다.
3. 기존 웹 앱 주소와 스크립트 속성은 유지합니다.

## 저장 방식
- 같은 설문을 여러 프로그램에서 재사용할 수 있습니다.
- 새 신청의 PDF·첨부파일은 실제 신청한 프로그램 폴더의 ‘신청서 모음’에 저장됩니다.
- 설문 응답 시트와 전체신청명단.csv도 해당 프로그램 폴더에 저장됩니다. 프로그램이 바뀌면 응답과 명단도 분리됩니다.
- 설문 관리 화면에서는 해당 설문을 사용한 프로그램들의 응답을 모아서 조회할 수 있습니다.
- 웹앱 신청 기록과 기본 개인정보 동의 보관 방식은 변경하지 않습니다.
- 빈 설문 PDF·문항 원본은 기관 폴더의 공용 ‘설문 양식 관리’ 아래에 둡니다. 신청할 때 설문별 통합 CSV를 추가로 생성하지 않습니다.

## 기존 자료
기존 설문_ID 폴더는 해당 설문을 다음에 사용할 때 ‘설문 양식 관리’ 아래로 이동하며 파일 주소는 유지됩니다. 기존 응답·CSV·PDF는 삭제하지 않습니다. 기존 응답은 계속 조회·수정할 수 있고, 새 신청부터 프로그램별 시트에 저장됩니다. 기존 기록 전체의 이전이나 중복 파일 삭제는 이번 수정에 포함하지 않습니다.

## 확인
코드 모의 테스트: 동일 설문 A/B 프로그램 분리, 프로그램별 CSV, 재제출 중복 방지, 통합 응답 조회, 신청정보 수정, 기본 동의 Google 제외, 기본형·첨부형 유지 통과.
운영 서비스에는 적용하지 않았습니다. 적용 후 같은 설문으로 서로 다른 프로그램에 신청하여 각 프로그램 폴더의 파일을 확인하세요.

되돌리기: 기존 google-apps-script-v90.gs로 교체하면 새 프로그램별 응답을 찾지 못하므로, 접수 후에는 v90으로 단순 되돌리지 말고 v91 저장 구조를 유지하는 수정본을 사용해야 합니다.
